Five Poly Haven colour-map samples for review, not approved level art.
Every downloaded original is 2048x2048 JPEG; each albedo_128.png is a real
128x128 Lanczos reduction. No source colour grading has been applied.

Open scenes/fidelity_texture_candidates.tscn and use F6. All samples use the
existing 50% filtering shader. The original fidelity_test.tscn is preserved.
The gallery uses a common four-metre texture repeat for comparison; final brick,
shutter and tile dimensions should follow the asset scale after selection.
The plaster is deliberately quiet; concrete 007 is a more weathered option.
Shutter is for roller doors, not a general smooth painted-metal substitute.
Floor tiles 06 is a checkered marble option for reception, not production floors.

The review sheet contains Godot renders, not provider PBR beauty previews.
