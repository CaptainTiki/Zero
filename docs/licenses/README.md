# Retained asset licence texts

Collected September 17, 2026. Asset-to-licence mappings and creator credits are in
[ATTRIBUTIONS.md](../ATTRIBUTIONS.md).

- `CC0-1.0.txt`: unmodified CC0 1.0 legal text downloaded from the
  [SPDX licence-text archive](https://raw.githubusercontent.com/spdx/license-list-data/main/text/CC0-1.0.txt).
  Official reference: https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt
- `kenney-impact.txt`: exact copy of `audio/cc0/kenney/impact/License.txt`.
- `kenney-scifi.txt`: exact copy of `audio/cc0/kenney/scifi/License.txt`.

The CC0 text explains the licence; individual source pages and bundled notices
establish which assets their creators released under it. These texts apply only
to the corresponding third-party assets, not to the whole project.
